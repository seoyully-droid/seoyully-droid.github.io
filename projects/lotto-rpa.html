01 / Overview

최신 10개 회차 수집부터 번호 통계까지 자동화

지정된 프로젝트명·폴더·파일명 규칙에 맞춰 최신 10개 회차의 당첨번호를 수집하고, Excel에서 1~45 번호별 출현 횟수를 계산하도록 구성했습니다.

10

수집 회차

조회일 기준 최신 회차부터 총 10개 회차를 반복 처리

45

통계 대상 번호

1번부터 45번까지 각 번호의 출현 횟수를 집계

프로젝트 / 프로세스

Lotto_김서율 / P_Lotto_김서율

결과 저장 규칙

yyyyMM 폴더에 yyMMdd_이름_Lotto.xlsx 형식으로 저장

03 / Workflow

자동화 흐름

STEP 01작업 폴더 생성 및 동행복권 접속
STEP 02추첨결과 페이지 이동

STEP 04Excel에 회차별 데이터 입력
STEP 0510개 회차 반복 처리
STEP 061~45 통계 헤더 생성
STEP 07COUNTIF 기반 번호별 출현 횟수 계산
STEP 08결과 파일 날짜 규칙에 맞춰 저장
STEP 09결과 Excel 확인
STEP 10자동화 종료
04 / Implementation

구현 포인트

회차 드롭다운 제어

회차 바로가기의 드롭다운을 제어해 최신 회차부터 순차적으로 10개 회차를 조회하도록 구성했습니다.

당첨번호 배열 처리

추출한 당첨번호에 회차 정보를 결합하고, 반복 처리 과정에서 Excel 입력 구조에 맞게 데이터를 구성했습니다.

Excel 자동 기록

B4부터 회차별 당첨결과를 행 단위로 입력하고, 전체 정렬·테두리 등 결과 형식도 자동 적용하도록 구성했습니다.

번호별 통계 계산

1~45 통계 헤더를 만든 뒤 WriteCellFormula와 COUNTIF 수식을 활용해 번호별 출현 횟수를 계산했습니다.
