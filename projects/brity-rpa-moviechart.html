영화 예매순위
수집 자동화

무비차트 예매순위에 등록된 영화의 상세 정보를 반복 수집하고, 지정된 Excel 양식과 파일 규칙에 맞춰 결과 파일을 자동 생성하는 RPA 프로젝트입니다.

Brity RPAChrome AutomationXPathWeb Data ExtractionExcel AutomationLoop / Condition
01 / Overview

과제 요구사항을 자동화 흐름으로 구현

프로젝트명과 저장 경로, 결과 파일명 규칙을 준수하면서 예매순위 1~20위 영화의 정보를 수집해 결과 Excel을 생성하도록 구성했습니다.

20

수집 대상

예매순위 1위부터 20위까지의 영화 정보를 반복 처리

7

수집 항목

순위, 예매율, 제목, 장르, 감독, 주연, 시놉시스

프로젝트 / 프로세스

MovieChart_김서율 / P_MovieChart_김서율

결과 저장 규칙

yyyyMM 폴더에 yyMMdd_이름_MovieChart.xlsx 형식으로 저장

03 / Workflow

자동화 흐름

STEP 01작업 폴더 및 Excel 양식 준비
STEP 02무비차트 홈페이지 접속
STEP 03예매순위 페이지 이동
STEP 04영화 상세 페이지 진입
STEP 05영화 정보 추출 및 변수 가공
STEP 06Excel 양식에 데이터 입력
STEP 07예매순위로 복귀 후 다음 영화 반복
STEP 08결과 폴더에 최종 파일 저장
04 / Implementation

구현 포인트

웹 객체 제어

ChromeClick, ChromeNavigate, ChromeGetData 등을 활용해 예매순위와 상세 페이지 사이의 이동 및 데이터 수집 흐름을 구성했습니다.

반복 / 조건 처리

영화별 추출 결과를 변수로 분리하고, 출연 정보 등 데이터 구조 차이를 조건 분기로 처리했습니다.

Excel 자동 기록

수집한 값을 지정된 열 구조에 맞춰 입력하고 결과 파일명 및 날짜 폴더 규칙에 맞춰 저장하도록 구성했습니다.

실행 오류 대응

페이지 로딩 시간과 웹 객체 인식 문제를 점검하며 자동화가 끝까지 실행되도록 테스트 및 수정했습니다.

05 / Demo

실행 영상

포트폴리오용 데모에서는 전체 흐름을 빠르게 확인할 수 있도록 반복 수집 건수를 임시로 축소했습니다.

실제 과제 기준은 영화 20건입니다. 시연 영상에서는 자동화의 동작 흐름을 짧게 보여주기 위해 수집 건수를 3건으로 임시 조정했습니다.

데모: 프로세스 실행 → 웹 데이터 수집 → 반복 처리 → Excel 결과 확인
