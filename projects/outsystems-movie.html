03 / Favorite Logic

즐겨찾기 데이터 관리

영화 자체가 아닌 사용자 관심 영화 데이터의 등록·수정·삭제 흐름 구성.

추가

Start → Assign → CreateFavorite → Refresh GetFavorites → End

수정

Start → Assign → UpdateFavorite → Refresh GetFavorites → End

삭제

Start → DeleteFavorite → Refresh GetFavorites → End

데이터 반영

  • GetFavorites Aggregate Refresh
  • 변경 결과 화면 반영
  • SelectedMovieId 기반 선택 데이터 처리
