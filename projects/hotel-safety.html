02 / My Role

담당 범위

팀 전체 기능과 개인 담당 영역을 구분해 정리.

OutSystems · 회원가입 / 인사 관리

  • 프로필 사진·기본정보 입력 화면 구성
  • 이메일 중복·휴대폰 형식·비밀번호 조건 검증
  • 가입 후 승인 대기 프로세스 구성
  • 본인 프로필 조회·수정
  • 직원 정보 조회 및 조건 검색
  • 부서·역할 지정 및 승인·거절 처리
  • HR_Manager / Root 기준 화면 접근 제어

Brity RPA · 인사 보고 자동화

  • 부서 선택 기반 로그인 자동화
  • 직원정보 화면 데이터 수집·Excel 저장
  • 부서·역할 정보 수집·Excel 저장
  • 반복 입력 및 서식 적용
  • 작성일자 기반 파일명으로 결과 저장
03 / OutSystems

회원가입 · 승인 · 권한 관리

가입 단계 검증

  • 이미 사용 중인 이메일 차단
  • 휴대폰 번호 형식 검증
  • 비밀번호 8자 이상 조건
  • 비밀번호 확인 일치 여부 검증

승인 프로세스

  • 가입 완료 후 승인 대기
  • 인사팀의 부서·역할 지정
  • 승인 / 거절 처리
  • 승인 전 로그인 접근 차단

직원 정보 관리

  • 사진·이름·부서·역할·이메일·연락처 조회
  • 이름·부서·역할 조건 검색
  • 비활성 계정 목록 제외

Role 기반 접근 제어

  • 부서·역할 관리 메뉴 제한
  • HR_Manager / Root 접근 허용
  • Manager · Staff · Registered · Anonymous 접근 차단
  • URL 직접 입력 접근 차단
04 / RPA

월간 보고 업무 자동화

OutSystems 화면 데이터를 수집해 Excel 보고서를 생성하는 Brity RPA 통합 프로세스 중 인사 관련 작업 담당.

2종

담당 보고서

  • 직원정보 현황 보고서
  • 부서 · 역할 정보 보고서

공통 처리 구조

  • 화면 데이터 수집
  • 새 Excel 생성·제목/작성일자/헤더 입력
  • 행 수만큼 반복 입력
  • 정렬·테두리 등 서식 적용
  • 날짜 기반 파일명으로 저장

로그인 자동화

  • 부서 번호 InputBox 입력
  • Switch로 부서별 계정 선택
  • 시스템 접속·아이디 입력·공통 비밀번호 입력
  • 업무에 맞는 권한 계정으로 로그인

팀 통합 결과

  • 직원정보 보고서
  • 부서·역할 보고서
  • 검사일정 월별 보고서
  • 장비정보 보고서
  • 시설정보 보고서
