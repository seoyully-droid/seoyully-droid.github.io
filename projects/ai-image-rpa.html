AI 이미지 분석·생성
및 결과 전송 자동화

이미지 파일을 AI로 분석하고 결과에 따라 분류한 뒤, 분석 결과를 기반으로 새 이미지를 생성·저장하고 전체 작업 결과를 이메일로 전송하는 Brity RPA 자동화 프로젝트입니다.

01 / Overview

AI 분석부터 생성·저장·메일 전송까지 하나의 흐름으로

작업 폴더를 준비하고 이미지별 분석을 반복 수행한 뒤 결과를 가공해 이미지 생성 요청으로 연결합니다. 생성된 파일을 분류·저장하고 최종 결과를 이메일로 전달하도록 구성했습니다.

입력 / 출력 폴더 관리

Input, Output, Temp 작업 폴더를 구분해 원본 이미지와 처리 결과를 체계적으로 관리했습니다.

이미지 분석 반복 처리

이미지 파일 개수만큼 분석 요청과 결과 처리를 반복하도록 자동화 흐름을 구성했습니다.

AI 이미지 생성

분석 결과를 기반으로 생성 프롬프트를 구성하고 API를 통해 새 이미지를 생성하도록 연결했습니다.

결과 메일 전송

분석·생성·분류 작업이 완료되면 최종 결과를 지정된 수신자에게 이메일로 전송하도록 구성했습니다.

02 / Workflow

자동화 흐름

STEP 01분석 대상 이미지 및 작업 폴더 준비
STEP 02이미지 업로드 및 AI 분석 요청
STEP 03분석 결과 확인 및 이미지 분류
STEP 04분석 결과 기반 이미지 생성 요청
STEP 05생성 이미지 저장 및 분류
STEP 06이미지 수만큼 반복 처리
STEP 07예외 결과 재요청 및 제외 처리
STEP 08전체 결과 이메일 전송
03 / Implementation

구현 포인트

Task 단위 모듈화

폴더 정리, 데이터 읽기, 이미지 분석, 분류, 이미지 생성, 메일 전송 등 업무 성격별로 Task를 분리해 구성했습니다.

변수 범위 구분

프로세스 전체에서 사용하는 값은 Global 변수로 관리하고, Task별 전달 값은 Input / Output 변수로 구분했습니다.

예외 처리

분석 결과가 의도한 기준과 다르면 1회 재요청하고, 재요청 후에도 기준과 다를 경우 해당 작업에서 제외하도록 처리했습니다.

API 응답 파싱

AI 분석·생성 API의 JSON 응답을 파싱해 분석 결과와 생성 이미지 데이터를 후속 Task에서 사용할 수 있도록 연결했습니다.

04 / Demo

실행 영상

AI 이미지 분석 결과, 이미지 생성·저장, 결과 확인 및 이메일 전송 흐름을 포트폴리오용으로 편집한 데모입니다.

데모 안내 정상 실행 시점의 결과 화면들을 기준으로 포트폴리오용으로 재구성한 영상입니다.
